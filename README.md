A beginner-friendly Linux Administration project demonstrating the setup and configuration of an Ubuntu Server inside VirtualBox.

---

## Project Objective

The goal of this project is to learn fundamental Linux system administration skills that are required for DevOps, Cloud Engineering, and System Administration roles.

---

## Technologies Used

- Ubuntu Server 24.04 LTS
- Oracle VirtualBox
- OpenSSH Server
- Linux CLI

---

## Skills Learned

- Linux Installation
- Shell Commands
- User Management
- Groups
- File Permissions
- SSH
- Basic Networking
- Troubleshooting

---

## Project Workflow

1. Install Ubuntu Server
2. Configure Networking
3. Update Packages
4. Install OpenSSH
5. Configure SSH
6. Create Users
7. Create Groups
8. Manage File Permissions
9. Troubleshoot Common Problems
